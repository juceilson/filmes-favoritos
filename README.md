# App Filmes Favoritos

Aplicativo Mobile desenvolvido em **Kotlin** e **Jetpack Compose** que permite os usuários pesquisar filmes através da API pública do **OMDb**, visualizar os detalhes e salvar seus filmes favoritos em um banco de dados local para acesso offline.

---

## Tecnologias e Bibliotecas Utilizadas
- **Kotlin**: Linguagem de desenvolvimento
- **Jetpack Compose**: para design das telas
- **Navigation Compose**: para gerenciar as rotas
- **Room Database**: para percistir os dados no SQLite
- **Retrofit 2**: para fazer requisições HTTP na *OMDb API*
- **Coil 3**: para carregamento assincrono das imagens e salvar em cachê
